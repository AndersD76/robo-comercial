# Diretórios e cadastros: onde listar o TurboVenda AGORA

## Como usar

- A lista está **em ordem de prioridade**. Os 5 marcados com ⭐ são pra fazer esta semana.
- Cada item traz o link de cadastro, o status da verificação, por que vale a pena, o link do site com UTM e o ajuste no texto, quando precisa.
- **Status da verificação** (feita em 17/10/2026):
  - **Verificado:** abri a página oficial (ou a documentação oficial) e o caminho de cadastro existe.
  - **NÃO verificado:** a página bloqueou o acesso automático (erro 403) ou o endereço não abriu daqui. Confira no navegador antes de contar com ele.
- **Link do site com UTM:** use `utm_source=diretorio&utm_medium=diretorio&utm_campaign=<nome-do-diretorio>`. No campo "site", use a ferramenta grátis de lista de empresas, que funciona sem login e é a melhor primeira impressão. Onde houver campo de "teste grátis" ou "cadastro", use o `/cadastro`. Os dois links já estão prontos em cada item.
- Cada cadastro também é um backlink (quando o diretório mostra link) e uma prova social de que a empresa existe.
