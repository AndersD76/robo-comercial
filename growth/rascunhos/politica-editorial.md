# Rascunho — política editorial (`/politica-editorial`)

**Status:** rascunho para revisão. Descreve o processo; confirme se é assim que vocês trabalham antes de publicar.

## Como os conteúdos são feitos
- **Números e estatísticas** vêm de fonte identificada, com data: dados abertos da Receita Federal (com o mês da base), páginas oficiais de preço dos concorrentes (com a data da consulta) e dados agregados do próprio TurboVenda (sem identificar clientes).
- **Comparativos** com concorrentes dizem para quem cada ferramenta é melhor, inclusive quando não é o TurboVenda, e mostram a data em que os preços foram conferidos.
- **TODO-VALIDAR:** uso de IA. Se os textos são escritos ou revisados com IA, dizer isso e dizer quem revisa (nome e função) antes de publicar.
- **Atualização:** cada artigo mostra a data de publicação e, quando revisado, a data de atualização. Páginas que perdem tráfego entram numa fila de revisão (`growth/fila-atualizacao.md`).

## Correções
Encontrou um erro? Escreva para suporte@turbovenda.com.br com o link da página. Corrigimos e registramos a data da atualização.
